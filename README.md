# Customer Churn Analysis

## Overview
This project analyzes customer churn behavior using multi-source datasets to identify key churn drivers and recommend actionable retention strategies. The analysis combines SQL-based data processing with an interactive Power BI dashboard.

---

## Key Objectives
- Identify who is churning and why  
- Analyze behavioral patterns before churn  
- Measure churn impact on revenue  
- Provide data-driven retention strategies  

---

## Tech Stack
- SQL (data cleaning, joins, aggregations)  
- Power BI (data modeling, DAX, dashboarding)  
- Excel (initial data handling)

---

## Data Overview
- Time period: Jan 2023 – Dec 2024  
- 500 total customers  
- 110 churned customers  
- ~22% overall churn rate  
- Multi-table dataset (customer, usage, revenue, support, churn)

---

## Dashboard Highlights
- 10+ interactive visualizations  
- Churn by country, industry, usage, and plan tier  
- Revenue impact analysis (ARPU, lost revenue)  
- Key influencers analysis for churn drivers  
- Interactive filters (cohort, trial, etc.)
